\# TCC - Sentinel Control



Sistema inteligente de monitoramento e segurança industrial utilizando Inteligência Artificial.



\## Objetivo



O Sentinel Control tem como objetivo auxiliar na segurança de ambientes industriais por meio do monitoramento de câmeras e identificação automática de Equipamentos de Proteção Individual (EPIs).



\## Tecnologias



\- Python

\- YOLO / Ultralytics

\- PyTorch

\- OpenCV

\- Node.js

\- MySQL

\- HTML

\- CSS

\- JavaScript



\## Inteligência Artificial



O projeto utiliza o YOLO para detecção de pessoas e EPIs em imagens e, futuramente, em transmissões de câmeras.



Atualmente está sendo utilizado o dataset Construction-PPE para treinamento e testes.
